# COS311_AI_Assignment

I used ChatGPT for this assignment. 

1. What concrete benefits did you see by utilizing AI to help you make the notebook?
\n I could see that it made mundane tasks a lot faster. If I asked it to do some nitty gritty stuff, it was fast to respond with the correct answer, and since it was a pretty simple assignment, the AI didn't particularly have any trouble with outputting the correct code. If I didn't understand that code, I could ask it and it would respond quickly with the answer, and teach me why it was creating the code that it was creating. I think benefits will be for someone who just need a starting code for a big project, it could speed up the process for them so that they don't need to do the mundane coding part. Another benefit I can see is for people who doesn't fully understand the code that they are writing, and they could ask it why it is wrong, or why the code they are writing works. 

2. What dangers do you see for someone using AI to make this notebook without learning data science properly? Give concrete examples. 
\n I can see that AI could lead to over reliance on it, which could lead to the person not understanding at all what they are writing. This could lead to data mishandling, where maybe the AI would delete the wrong rows, or mishandle missing values lines instead of using a better technique. It could also lead to the person being in a job where they are under-qualified, and not recognizing when AI is giving them the wrong code for what they were tasked to do. It could also put them in a sticky situation where they need to write their own code and they do not know how to approach it at all because of their over-reliance on AI. 

3. Give examples where you needed to verify the AI output for correctness. How did you know to verify those outputs? 
\n For the percentage bar graphs, the AI didn't stack the bars together, so I needed to correct it by asking it to stack them together, which the AI complied quickly. I knew to verify these outputs since I had the other project that we already worked on to compare it with.
